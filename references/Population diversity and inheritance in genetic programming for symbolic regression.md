# Population diversity and inheritance in genetic programming for symbolic regression

- Citation: Burlacu, B., Yang, K., & Affenzeller, M. (2024). *Population diversity and inheritance in genetic programming for symbolic regression*. Natural Computing, 23, 531-566. https://doi.org/10.1007/s11047-022-09934-x
- Source checked: Springer article page, open access.
- Local PDF: `Population diversity and inheritance in genetic programming for symbolic regression.pdf`
- Why this paper matters:
  - 構造多様性を genotypic similarity として定義する際の直接の根拠
  - semantic similarity を相関ベースで定義する際の直接の根拠
- Information used in this project:
  - 構造類似度 `Sim_g` を部分木対応の Jaccard 類似度で定義する方針
  - 意味類似度 `Sim_p` を出力ベクトルの二乗相関で定義する方針
  - 類似度から `1 - average similarity` として多様性を置く考え方
