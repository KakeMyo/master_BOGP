# Seminar最終条件：状態観測あり／なしBOの比較

2026-10-01に追加実験。既存の研究資料と実験結果は変更していない。

## 比較の定義と条件

「観測なし」はGP状態を代理モデルの入力に与えない非文脈BOを指す。BOは操作率と実際に得た報酬を学習する。報酬自体を観測しない方式ではない。報酬計算と評価用の状態計測は両条件で続けるため、この比較は状態情報の利用効果であり、状態計測を省く計算コストの比較ではない。

Seminar最終版のFriedman-I、訓練200点・テスト200点、集団24、78世代（warm-up18＋本評価60）、seed 0〜99、1実行1872評価、training NRMSEと式木サイズの2目的、archive上限200、構造キーtopology_value、HV参照点(1,1)を使用。データは既存問題実装と共通。テスト誤差は今回の主要比較には用いていない。

- 観測あり：進行度、archive HV、直近HV増分、構造多様性、平均木サイズ、停滞の6次元と操作率2次元を入力。
- 観測なし：操作率2次元のみを入力。Matern ARDカーネルの入力次元だけ8→2へ変更。
- 共通：k∈{1,3,5}別surrogate、per-k EI、各kで2回のwarm-up、候補点数、乱数seed、平滑化、率の範囲と更新幅制約、報酬を維持。
- 残り世代数に応じたkの実行可能性判定は両条件で維持する。進行度は観測なし側の予測入力には与えない。

全100 seedで、観測ありの全世代履歴が2026-06-03のSeminar最終実験保存結果と完全一致。両条件の最初の6制御区間（18世代）の記録も完全一致し、評価回数1872を確認した。同じwarm-up後集団から比較している。

## 結果

標準偏差は100試行の母標準偏差。HVは大きいほど良い。AUCは世代18〜78の台形積分を60で除した平均HV。

|---|---:|---:|
| 最終archive HV（平均±SD） | 0.802461 ± 0.022454 | 0.802270 ± 0.030345 |
| 最終HV中央値 | 0.800704 | 0.799832 |
| warm-up終了HV平均 | 0.740278 | 0.740278 |
| warm-up後HV増加平均 | 0.062183 | 0.061992 |
| warm-up後平均HV（AUC、平均±SD） | 0.787353 ± 0.025021 | 0.785468 ± 0.040473 |
| 最終構造多様性（平均±SD） | 0.640513 ± 0.086765 | 0.638855 ± 0.102982 |
| 最終集団の平均木サイズ | 10.427917 | 10.665000 |
| 制御更新回数平均（warm-up含む） | 32.48 | 29.30 |
| 本評価中の制御更新回数平均 | 26.48 | 23.30 |
| 最終HV最小値 | 0.751448 | 0.652827 |
| 最終HV最大値 | 0.853518 | 0.869018 |

同一seed差（観測あり−観測なし）の最終HV平均は+0.000191、相対差約+0.024%。対応ありt区間95% CIは[-0.005478, +0.005859]、対応ありt検定p=0.947、Wilcoxon符号付順位検定p=0.408。43勝・5引分・52敗（判定許容差1e-12）、差の中央値は−0.000902。平均性能の優位性は示されず、同等性を証明したわけでもない。

AUC差は+0.001885、95% CI [-0.003917,+0.007687]、対応ありt検定p=0.521で、平均的な収束速度の改善も明確ではない。

最終HV標準偏差は観測ありで約26.0%低い。seed対を単位として20,000回再標本化したpaired bootstrapによるSD差の95% percentile CIは[-0.016234,-0.000504]（乱数seed 20261001）。今回の100 seedではばらつき低減を支持するが、他の問題への一般化は未検証。AUCのSDも約38.2%低い。

最終HVの5%分位は0.773619対0.772076、10%分位は0.777284対0.777234で非常に近い。分布全域が一様に改善したわけではない。観測なしではHV0.75未満が2試行、観測ありでは0試行（0.75は事後の説明用閾値）。SD差には少数の大きな失敗と高成績側の広がりが影響している。

## 制御挙動

|---|---:|---:|

| 3 | 616（23.3%） | 577（24.8%） |
| 5 | 530（20.0%） | 629（27.0%） |

観測ありは短いkを多く選び、更新回数が平均3.18回増えた（95% CI [+0.7995,+5.5605]）。短周期化によって状態変化への応答機会が増え、極端な失敗を抑えた可能性がある。ただし今回だけでは「短周期化が安定化の原因」とは断定できない。kを揃えた比較が必要である。実行時間や計測コストの優劣は今回測定していない。

本評価中の各runの平均操作率をさらにseed平均すると、p_cは0.713562対0.695415、p_mは0.140297対0.141022。突然変異率平均はほぼ同じだが、交叉率とkの選び方は変化した。平均操作率だけから個々の状態への反応を説明することはできない。

## 考察

1. **現条件では、状態観測による平均HVの上乗せは確認できない。** 固定率標準GPの0.782991に対して、観測ありと観測なしの両方が約0.802となる。したがって、以前の固定率との比較だけでは、その差を文脈情報の効果と解釈できない。共通のwarm-up、報酬に基づく操作率探索、k制御などの寄与が混ざっている。高突然変異固定率の0.808315には両条件とも平均で届かない。

2. **状態観測は、平均を上げるよりseed間の極端な結果を抑える方向に働いた可能性がある。** 大半のseedでは小差にとどまり、観測なしの方が勝つseedも多い一方、大きな失敗を避けるseedがある。例としてseed23ではHV差+0.138720、seed75では+0.083383。しかしseed52では−0.108791となり、観測が常に有効という説明は不適切。観測なしの最大HVも観測ありより高い。

3. **warm-upで改善の大部分を得る条件では、文脈の上乗せ効果を検出しにくい。** 共通の18世代で、観測ありの初期〜最終平均HV改善の約82.2%を得ている。残る探索の余地が小さい。ただしwarm-up後改善量も両条件でほぼ同じなので、最終HV評価だけが差を隠したとは言えない。

4. **状態と報酬の関係を学ぶデータが少ない。** 本評価中の更新は平均26.48回／23.30回で、さらにk別モデルに分かれる。観測ありは8次元、観測なしは2次元の入力である。状態依存性を表現できる利点と、少量データで学習しにくい不利が共存する可能性がある。学習不足そのものは今回の結果では直接検証していない。

5. **報酬最大化と最終HV最大化は一致しない。** warm-up後の全制御区間を等重みで集計した報酬平均は観測あり0.047159、観測なし0.059945。観測なしの方が報酬は高いが最終HVはほぼ同じ。kと区間時期が異なるため、この平均を直接の性能ランキングには使えない。多様性目標への一致と更新コストが報酬を左右することを示す診断値として扱う。

## 報酬項分析に向けた確認

Seminar版の報酬は r=0.55 HV項+0.35多様性一致項−0.05更新コスト−0.25多様性下限罰則。停滞・bloat罰則は計算されるが重み0である。

HV項は区間のarchive HV改善を世代数で割り0.01で正規化し[-1,1]にclip。多様性項は区間平均多様性と、進行度に応じ0.60→0.20へ下げる目標との一致度で、高い多様性を一律に報いるものではない。更新コストはk=1で1、k=3で0.5、k=5で0となる。多様性が0.10を下回ると下限罰則が発生する。

今回、報酬項を変更する実験は行っていない。各項の因果的な働きを評価する次段階では、同じseed・warm-upを保って各有効項を一つずつ無効化する比較が必要。停滞・bloat項は「除去」では変化しないため、検討するなら重みを有効にする追加比較として分ける。

## 発表用の説明

> 状態情報を用いないBOと比較した結果、最終HVの平均には明確な差がなかった。一方、状態情報を用いる提案法は短い更新周期を多く選び、最終HVのseed間標準偏差を約26%抑えた。この条件では、観測の効果は平均性能向上より探索結果の安定化として現れた可能性がある。ただし個々のseedで必ず改善するわけではなく、k制御との切り分けと他問題での再検証が必要である。
