## 1. 結論

**次の検証の優先順位はAirfoil、Concrete、UBall5D。**
理由は提案法の勝敗だけでなく、固定率条件を含めて18世代後・終盤に改善が続くかと、
非定数の回帰式を探索できているかである。

| 問題 | 提案法の最終HV平均 | 高突然変異の最終HV平均 | 提案法の18世代後HV増加平均 | 今回確認できた傾向 |
|---|---|---|---|---|
| UBall5D | 0.798186 | 0.797092 | 0.018752 | 提案法3回とも最終的な訓練最良式が定数。現在の構成では、求める長期の構造探索には不十分 |
| Airfoil | 0.829705 | 0.811336 | 0.015194 | 提案法3回とも18世代後に改善。2回は60世代以降にも改善。最も継続検証しやすい |
| Concrete | 0.824499 | 0.828383 | 0.001030 | 提案法2回は18世代までで停止。高突然変異では2回に後半の改善があり、早期停滞・制御の副検証に向く |

## 2. 今回の条件

### 2.1 セミナーから維持した条件

初期の「総30世代」スクリプトではなく、最終レジュメ
`paper_8page_2col_draft_expanded.tex` の設定と
`run_main_bo_current_friedman_experiment.py` を基準とした。

| 項目 | 設定 |
|---|---|
| 集団・世代数 | 24個体、ウォームアップ18＋本評価60＝総78世代 |
| GPシード | 0, 1, 2。各問題の全比較法に同じデータと初期化seedを使用 |
| 目的 | 訓練NRMSE、木サイズを最小化するNSGA-II型MOGP |
| 訓練誤差の扱い | RMSE / 訓練targetの標準偏差、目的値を[0,5]へクリップ |
| 木サイズ・HV | 木サイズの正規化範囲[1,100]、HV参照点(1,1)。100はハード上限ではない |
| 関数・定数 | add, sub, mul, protected div, sin, cos。ERC[-2,2] |
| 初期化・変異 | 初期深さ5、変異部分木深さ2。終端/変数生成確率も既存実装のまま |
| 数値保護 | abs(分母)≤1e-6なら分子を返す。予測を±1e6へクリップ |
| 生存・アーカイブ | tournament size=3、archive=200、topology_valueによる重複管理 |
| 標準固定 | pc=0.80, pm=0.05 |
| 高突然変異固定 | pc=0.70, pm=0.20 |
| 高交叉固定 | pc=0.90, pm=0.05 |
| 提案法 | 既存BO制御器・報酬を変更せず使用。k∈{1,3,5}を各2回sequential warm-up |
| 評価予算 | 初期24＋子集団24×78＝1896訓練fitness呼出/実行（セミナー表の1872は初期分を除く） |

今回の36実行で合計68,256訓練fitness呼出。検証/testの検索後評価はこの数に含めない。
BOによるkは更新周期であって、tournament sizeではない。

### 2.2 新問題のデータ仕様と前回案との差

| 問題 | 訓練 | validation | test | 入力数 | 前処理 |
|---|---|---|---|---|---|
| UBall5D | 1024 | 独立1024 | 独立5000 | 5 | rawを保持、noiseなし |
| Airfoil | 901 | 225 | 377 | 5 | trainだけでX/yをz-score標準化 |
| Concrete | 614 | 156 | 260 | 8 | 同上 |

データ生成・分割seedは20260527で固定し、GPシードと分離した。
今回は1つのデータ分割での3回であり、3つの別splitによる評価ではない。

UBallの式は `10/(5+sum((xi-3)^2))`。train/validationは各入力U[0.05,6.05]、
testはU[-0.25,6.35]である。[R29, Table 5]
validationの追加は本研究の拡張であり、文献のcanonical train/testを変えていない。

実データは[UCI Airfoil](https://archive.ics.uci.edu/dataset/291/airfoil%2Bself%2Bnoise)と
[UCI Concrete](https://archive.ics.uci.edu/dataset/165/concrete%2Bcompressive%2Bstrength)の公式配布物を保存した。
出典・CC BY 4.0・取得URLは[data README](../data/problem_settings/README.md)に記録。
Concreteには同一入力の重複34行（うち完全同一行の重複25行）があった。
除外せず、同じ入力の全行を同じpartitionにまとめた。
unique-input groupの60/15/25%分割なので、行数比率は厳密な60/15/25%ではない。
元ファイル・数値のhash、split行番号、scaler統計を各問題のmanifestに保存した。

セミナーの基本条件を優先したため、前回案のpopulation=100、120/318世代、sqrt/log/AQ追加、
出力のfitted linear scaling、hard node capは**今回は使っていない**。
訓練由来のz-scoreは出力式への線形係数最適化とは異なる。
実データの最終出力は `y_hat=mu_y+sigma_y*g((X-mu_X)/sigma_X)` として元単位へ戻す。
これらはLiu等の完全再現実験ではなく、現行セミナー実装への移植pilotである。

## 3. 各問題の傾向

### 3.1 UBall5D：現条件では長期主問題へ進めない

- 提案法の3回はすべて入力変数を一つも使わない定数式になった。訓練NRMSEは1.000449。
  訓練平均を予測する定数のNRMSE=1とほぼ同じで、真の5変数関係を学べていない。
- 標準固定の平均訓練NRMSEは0.979610で、seed=1だけは12ノードの非定数式へ進んだ。
  平均最終HVも標準固定0.802433が提案法0.798186より高かった。
- 提案法のq_W中央値は96.7%、t90中央値は13世代。
  seed=0,1の18世代後HV増加は0.000539、0.004930。
  seed=2では0.050785増えたが、最終式は `cos(sin(-1.301498...))` という定数であり、
  平均改善量0.018752を「長く真の構造を探索できた」とは解釈できない。
- 5変数の真値は、現行四則演算と[-2,2]内の定数を組み合わせて100ノード以内で表現できる。
  その式を実装で評価して訓練/testのNRMSE<1e-12になるテストが通った。
  表現が不可能なのではなく、少数個体・誤差/サイズの探索でそこへ到達できていない。
- testは外挿範囲なので、訓練定数式のtest NRMSE>1は不自然ではない。
  提案法のtest NRMSEは1.095231だが、この値による候補選定・調整はしない。

判断: **今回の条件のまま「遅く収束する主合成問題」として採用しない。**
問題自体は候補から削除せず、まず固定率のみで集団サイズ・表現条件と小木縮退の影響を調べる別案として保持。
改善不能な停滞を、長期改善余地と取り違えない。

### 3.2 Airfoil：18世代後の改善を調べる次の最優先候補

- 提案法の18世代後HV増加はseed順に0.027427、0.016051、0.002104で、3回すべて正。
  seed=0,1は60世代以降も0.007247、0.004500改善した。
- 提案法のq_W中央値32.8%、t90中央値63世代。
  ただしseed=2はq_W=96.4%、t90=18なので、すべての実行が遅いわけではない。
- 固定率側にも改善余地がある。標準固定はq_W中央値18.8%、t90中央値55世代、
  高交叉も18世代後HVが平均0.011628増加した。
  高突然変異は平均0.002271にとどまり、現条件では強い突然変異が常に最良とは限らない。
- 提案法の最終HVは高突然変異を3/3回、標準固定と高交叉をそれぞれ2/3回上回った。
  高突然変異との平均差は+0.018369。
  ただし標準固定の18世代後HV増加平均0.017507は提案法の0.015194より大きく、
  「後半改善量でも常に提案法が最大」とはいえない。
- 提案法の平均訓練NRMSE0.842010、validation NRMSE0.833438は全固定条件より低かった。
  test NRMSEは提案法0.887056、標準固定0.877193で、標準固定の方が低い。
  高い訓練HVから汎化上の全面的優位を結論してはいけない。

判断: **継続探索を観察できる候補として、次の固定率・長期pilotを優先する。**
提案法が勝ったから本番問題へ決定するのではなく、未使用のdiscovery seedで固定率のみを再確認する。
単一splitの3回では統計的優位も、制御状態ごとの最適操作率の切替も証明していない。

### 3.3 Concrete：提案法の早期停滞を調べる副候補

- 提案法seed=0,1は、標準化したcement（x1）だけを使う同じ6ノード式
  `sin(sin(sin(sin(sin(x1)))))` に止まった。両方とも18世代後HV増加=0。
- 提案法seed=2は18世代後0.003089伸びたが、3回の平均は0.001030。
  q_W中央値100%、t90中央値13世代で、今回の提案法にとって安定した長期改善問題ではなかった。
- 一方で高突然変異のseed=1,2は、18世代後に0.033050、0.003279改善し、t90は74、71世代。
  したがって「問題そのものが18世代で必ず解ける」のではなく、探索条件によって後半の改善が残る。
- 平均最終HVは高突然変異0.828383、提案法0.824499で、高突然変異が上。
  提案法−高突然変異の平均差は−0.003884、勝ち/同点/負けは1/1/1。
- 提案法の訓練NRMSE0.875742は高突然変異0.854437より悪い。
  validationでも高突然変異0.851602に対し提案法0.858443で、優位を確認できない。

判断: **現状の提案法での長期主問題としては優先度を下げる。**
固定率では後半改善があるため、早期小木停滞・warm-up・多様性維持を診断する副実験には残す。
今回だけから突然変異率や報酬が原因だとは特定できない。

## 4. 指標の読み方と限界

`q_W=(H*_18-H*_0)/(H*_78-H*_0)`。H*は履歴最大HV。
`t90=min{g : H*_g >= H*_0+0.9*(H*_78-H*_0)}`。
全改善=0のときは定義不能としてn.a.を返す。
今回は36実行で生HVの減少がなく、生HVと履歴最大HVが一致した。
大きいq_Wは「今回の有限予算の改善が早期に集中」を表し、真の収束の証明ではない。

test/validationのNRMSEは各partitionのtarget標準偏差で正規化し、検索目的の[0,5]クリップはせず報告する。
予測の±1e6クリップは検索と共通。原単位RMSEとR²も保存する。
検索後に、各世代で訓練目的最小（同点なら小さい木）の式だけを未見データへ適用した。
テスト最良式を選ぶ操作は行っていない。
これらはtest上のPareto HVではなく、訓練選択した1本の式の診断値である。

NRMSE=1の1ノード定数式でも、今回の誤差上限5・HV参照点ではHV=0.8になり得る。
**HVが約0.8だから80%の予測精度がある、という意味ではない。**
誤差、式の変数依存、小木の占有、終盤改善を併せて確認する。
実データの標準化は探索空間も変えるため、従来Friedmanの絶対HVとの差を問題難度の純粋な差とみなさない。

3回はいずれも同一split上の探索乱数の反復。独立データsplitの不確実性は未評価。
今回使ったseedとtestを新しい本番比較の未使用データとは扱えない。
元案の長期採用基準を検証する120/318世代のcontroller-blind screenは未実行である。
