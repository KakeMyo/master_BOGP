# Overleaf Project Skeleton

This directory contains a minimal LaTeX project that can be uploaded to
Overleaf as a standalone paper workspace.

## Files

- `main.tex`: main entry point
- `sections/`: paper sections split into separate files
- `references.bib`: BibTeX database placeholder
- `figures/`: figure assets

## Suggested workflow

1. Create a new blank project in Overleaf.
2. Upload the contents of this `overleaf/` directory.
3. Set the title, author, and section contents as needed.
4. Add bibliography entries to `references.bib`.
